# Conquest Reforged integration

Conquest Reforged is an optional enrichment target for GeoStrata, not a core dependency.

Planned responsibilities for this bridge include suitable Conquest palette mappings, decorative geological set dressing, structures and replacement-tag extensions where Conquest terrain blocks are valid geological hosts.

The preserved `reference/` data is inventory/research material only. Do not copy large Conquest block lists into GeoStrata core. Compatibility data should live here (or in a separately distributed compatibility artifact) and must be safe to omit entirely.
